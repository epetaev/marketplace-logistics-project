# marketplace-logistics-project
Сквозной аналитических проект: выгрузка данных из БД(SQL), предобработка и расчет метрик логистики маркетплейса (Python/Pandas), интерактивная BI-визуализация возвратов (Yandex DataLens)

# Анализ эффективности логистики и возвратов на маркетплейсе

Сквозной проект по анализу логистических показателей селлеров и служб доставки. Цель проекта — выявить проблемные зоны в цепочке поставок, рассчитать долю возвратов и локализовать «токсичных» контрагентов.

## Стек технологий
* SQL: написание запросов, агрегация данных, фильтрация.
* Python (Pandas): очистка данных, группировка, расчет бизнес-метрик.
* Yandex DataLens: проектирование модели данных (датасетов) и сборка интерактивного дашборда.

## Ключевые этапы проекта
1. Выгрузка данных: Написан оптимальный SQL-запрос для агрегации заказов и возвратов в разрезе продавцов и логистических компаний.
2. Предобработка в Python: В Google Colab данные очищены от пропусков, приведены к нужным типам, рассчитана целевая метрика — *Доля возвратов*.
3. BI-аналитика: Данные импортированы в Yandex DataLens, настроено динамическое форматирование и фильтрация по типам продавцов.
